# Clearing Atlas artwork

The artwork is decorative. It does not depict transaction records, actual routes, or market values. Each file is delivered from the application's own origin.

The original generated Clearing Globe cover is used on the Operations overview. The prompt describes a navy enamel terrestrial globe, brass orbits, blue wire transfer arcs, and a quiet left side for copy. The 1280 × 720 and 720 × 405 WebP encodes are responsive sizes of the same illustration. The original SVG plates below were authored for this repository and are distributed under its license. None uses assets from the reference websites.
